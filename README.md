# 試験合格コーチ

情報処理技術者試験の学習を、チャット形式で伴走するWebアプリです。iPhoneのホーム画面に追加すると、アプリとして全画面で動き、オフラインでも使えます。

| アプリ | 内容 |
|---|---|
| [支援士合格コーチ](sc/) | 情報処理安全確保支援士試験。学習計画、4択（科目A-2）、記述、事例演習（科目B形式）、進捗 |
| [ネスペ合格コーチ](nespe/) | ネットワークスペシャリスト試験。同じ構成で、科目B-1・B-2に合わせた計画 |

アプリ独自の4択・記述・事例演習の問題はオリジナルです。これとは別に、メニューの「IPAの過去問」で、IPAが公表している直近5年分（令和3〜7年度）の過去問を解けます。

| 科目 | 支援士 | ネスペ | 解き方 |
|---|---|---|---|
| 科目A-2（午前II） | 10回分・250問 | 5回分・125問 | 4択。回ごとに本番形式（40分）、ランダム、未回答、間違えた問題 |
| 科目A-1（午前I・高度試験共通） | 10回分・300問 | 同左 | 4択。回ごとに本番形式（50分）など |
| 午後 | 科目B（150分）5回分、旧午後II（120分）5回分 | 科目B-2（旧午後II・120分）5回分 | 本番演習。問題冊子を問ごとに表示し、タイマー（中断・再開できる）と解答メモで解き、解答例と採点講評で自己採点 |

試験日程はIPAの発表を2026年11月11日時点で確認したものです。申込の前に[IPAの公式サイト](https://www.ipa.go.jp/shiken/)で最新情報を確認してください。

## 続けやすくするしくみ

- **続きから**：4択・今日の学習・IPAの過去問・事例演習は1問ごとに保存します。途中でやめても、メニューの一番上の「続きから」で再開できます（途中の演習は1つだけ保存し、別の演習を始めると置き換わります）。
- **記述の下書き**：入力のたびに問題ごとに保存し、「やめる」でも消しません。メニューの「書きかけの記述を続ける」から再開できます。
- **午後の本番演習**：アプリを閉じたり別の画面に切り替えたりした間は、タイマーを自動で止めます。経過時間は分単位で表示し、「時間を隠す」で隠せます。「終了」は時間が残っていれば確認してから解答例を出します。
- **過去問の本番形式**：「← 前の問題」で戻れます。全問答えたあと、採点の前に答えを見直せます。
- **短く始める**：メニューは「次にやること」を大きなボタン1つで示します。「1問だけ」でも今日の学習済みになり、「10分だけ」は10分たつとお知らせします。
- **やった量を見せる**：画面上部は「今日○問」、学習のあとに、この7日間のカレンダー（✓）とこれまでに解いた問題の数を表示します。
- **解説**：最初の1文だけを表示し、続きと図解は「くわしく」に、略語の正式名称は「略語：…」に畳んでいます。

## 解説の図解と略語

- アプリ独自の4択・記述・事例演習の解説に、仕組みを示す図解を付けています（支援士25種・ネスペ24種）。図は `src/<アプリ>/d_fig.js` に書き、`FIGMAP` で問題に割り当てます。
- 問題・選択肢・解説に出てくる略語は、解説の下の「略語：…」をタップすると正式名称（英語と日本語）を表示します。辞書は `src/common/d_abbr.js`（248語）です。
- IPAの過去問は画像で、解説も公表されていないため、図解と略語の表示はありません。

## IPAの過去問について

- 問題は、IPAが公表している問題冊子PDFのページを1問ずつ切り出した画像です。問題文の書き換えはしていません。スマホでは読みやすいよう、行を左右に分けて折り返した画像を表示しています（レイアウトを変更しています）。
- 正解はIPAが公表している解答例によります。解説は公表されていないため、正解だけを表示します。
- 各問に「出典：令和6年度 春期 情報処理安全確保支援士試験 午前Ⅱ 問1」の形で出典を表示しています。IPAの[試験に関するよくある質問](https://www.ipa.go.jp/shiken/faq.html)（「その他」の過去問題の使用について）に従って利用しています。
- 午後のページは、PCやタブレットではページ全体を、スマホでは本文を折り返したかたまりと図表に分けて表示します（レイアウトを変更しています）。
- 取り込み直すときは `python3 tools/past/make_past.py` を実行してから `python3 tools/build.py` を実行します（必要なものはスクリプトの先頭に記載）。

## 使い方

1. GitHub Pagesで公開したURL（`https://makomako-4568.github.io/shiken-coach/`）をiPhoneのSafariで開く
2. 使いたいアプリを開き、共有ボタン →「ホーム画面に追加」

学習記録は端末の中（ブラウザの保存領域）に保存されます。別の端末とは共有されません。

## 公開の設定（最初の1回だけ）

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。

## ファイル構成

```
index.html             入口ページ        ┐
sc/ , nespe/           公開するアプリ     ┘ tools/build.py が書き出す（直接は編集しない）
src/sc/ , src/nespe/   アプリの元になる部品
  h_head.html          見た目（CSS・画面の骨組み）
  d_*.js               試験情報と問題データ
  d_fig.js             解説の図解
  e_engine.js          処理（計画・出題・採点・保存）
src/common/d_abbr.js   略語の正式名称（両アプリ共通）
  d_past.js            IPAの過去問の正解とPDFへのリンク（tools/past/make_past.py が生成）
sc/past/ , nespe/past/ 科目A-2の問題画像    ┐
common/am1/            科目A-1の問題画像    │ tools/past/make_past.py が生成
sc/pm/ , nespe/pm/     午後のページ画像     ┘
tools/build.py         部品を組み立てて、公開用のファイルを書き出す
tools/past/            IPAの過去問を取り込むスクリプト
```

## 問題を追加・修正するとき

1. `src/<アプリ>/` のデータファイルを編集する
   - 4択：`c` の先頭が正解です。表示するときに並べ替えます。正解だけが長くならないように、選択肢の長さをそろえます
   - 記述：`k` は採点に使う語のグループです。解答例 `a` が、すべてのグループの語を含むようにします
2. `python3 tools/build.py` を実行する（Python 3 と Pillow が必要）
3. 変更をコミットして `main` にプッシュする

アプリを開くとデータの検査が動き、問題があればブラウザの開発者ツールのコンソールに表示されます。
